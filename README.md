# extrusion

## 1. 概要

このプログラムは、2次元の断面形状を3次元の経路に沿って押し出し、立体形状を描画する OpenGL/GLUT のサンプルプログラムです。

入力データとして、断面形状 `crossSection` と、押し出しの中心線となる経路 `spine` を与えます。プログラムは各節点で断面の向きを調整しながら断面を順に配置し、隣り合う断面同士を四角形ポリゴンでつないで側面を作ります。さらに、始点と終点にはキャップを付けて閉じた立体として表示します。

表示された形状は、マウスのドラッグで回転できます。この回転操作にはクォータニオンを使ったトラックボール方式が用いられており、直感的に 3 次元形状を観察できます。

## 2. プログラムの説明

### 2.1 ファイル構成

- `main.cpp`
  ウィンドウ作成、OpenGL の初期化、描画コールバック、マウス操作、キーボード操作を担当します。
- `extrusion.cpp`, `extrusion.h`
  押し出し形状そのものを生成して描画する処理を担当します。
- `quaternion.cpp`, `quaternion.h`
  クォータニオンの積と、クォータニオンから回転行列を作る処理を担当します。

### 2.2 全体の処理の流れ

このプログラムの流れは、概ね次のとおりです。

1. `main.cpp` で断面形状 `crossSection` と経路 `spine` を定義する。
2. GLUT でウィンドウを作成し、描画関数 `display()` などのコールバックを登録する。
3. `display()` で視点と光源を設定し、`extrusion()` を呼び出して押し出し形状を描画する。
4. マウスドラッグに応じてクォータニオンを更新し、形状全体の回転行列を作り直す。
5. 再描画のたびに、最新の回転行列を使って立体を表示する。

### 2.3 押し出し形状生成アルゴリズム

`extrusion()` は、断面形状を経路に沿って順に配置し、側面と端面を描くことで立体を作っています。

#### 2.3.1 断面と経路の入力

- 断面 `cs[][2]` は x-y 平面上の 2 次元多角形です。
- 経路 `sp[][3]` は 3 次元空間中の折れ線です。
- `nc` は断面の頂点数、`ns` は経路の節点数です。

つまり、2 次元の多角形を、3 次元の折れ線に沿って押し出すという構成になっています。

#### 2.3.2 断面の法線ベクトルを求める

側面に正しく法線を与えるため、最初に断面の各辺から 2 次元法線ベクトル `n[i]` を求めています。

各辺の差分を

- `x = cs[i][0] - cs[i - 1][0]`
- `y = cs[i][1] - cs[i - 1][1]`

として、正規化した法線

- `n[i][0] = y / a`
- `n[i][1] = -x / a`

を作ります。これが後で側面のライティング計算に使われます。

#### 2.3.3 起点断面の向きを決める

断面は元々 z 軸方向を基準に置かれています。そこでまず、経路の最初の線分方向を求め、`turn()` を使って「z 軸方向の断面」を「最初の線分方向を向く断面」に回転させます。

その後、`transform()` によって断面の全頂点を起点位置 `sp[0]` に移動し、最初の断面を配置します。

#### 2.3.4 各節点で断面を補正しながら進む

経路の途中の各節点では、進入方向ベクトルと退出方向ベクトルが一般には一致しません。そのまま単純に断面を置くと、折れ曲がり部分で形状が不自然になります。

このプログラムでは、各節点で次の処理を行います。

1. 進入方向と退出方向の単位ベクトルを求める。
2. それらの和を中間ベクトル `h` とする。
3. `shear()` を使って、この中間ベクトルに整合する断面変換を求める。
4. `transform()` で節点位置に断面を配置する。
5. 直前の断面と現在の断面を `side()` で結び、側面を描く。
6. `turn()` と `multiply()` を使って、断面の向きの基準行列を次の線分方向へ更新する。

ここで重要なのは、節点で単に回転するだけではなく、`shear()` によって断面を補正している点です。これにより、折れ線経路の曲がり角でも断面同士のつながりが比較的自然になります。

#### 2.3.5 側面の描画

`side()` では、前の断面 `p1` と現在の断面 `p2` の対応する頂点を結び、各辺ごとに四角形を 1 枚ずつ描いています。

概念的には、

- `p1[i - 1]`
- `p1[i]`
- `p2[i]`
- `p2[i - 1]`

で囲まれる帯を並べていくことで、押し出し面を作っています。

法線は 2 次元断面の法線を現在の断面の回転行列 `m` で 3 次元へ変換して求めています。これによりライティング時に側面の向きが正しく反映されます。

#### 2.3.6 端面の描画

始点と終点では `cap()` を使って断面に蓋をします。

`cap()` は GLU テセレータを使って多角形を三角形分割し、複雑な断面でも端面を描けるようにしています。始点では法線を逆向き、終点では順向きにして、閉じた立体になるようにしています。

### 2.4 座標変換の補助関数

`extrusion.cpp` には、押し出し処理を支える補助関数が実装されています。

- `multiply()`
  3x3 行列同士の積を求めます。
- `rotation()`
  任意軸回りの回転行列を作ります。
- `turn()`
  ある方向ベクトルを別の方向ベクトルへ向ける回転行列を作ります。
- `shear()`
  節点で断面を補正するためのせん断変換を作ります。
- `transform()`
  2 次元断面を回転・平行移動して 3 次元頂点列へ変換します。

これらを組み合わせることで、断面の姿勢を保ちながら経路に沿って押し出す処理を実現しています。

### 2.5 画面表示と操作

`main.cpp` の表示処理は次の役割を持っています。

- `display()`
  画面のクリア、視点変換、光源設定、回転行列の適用、押し出し形状の描画を行います。
- `resize()`
  ビューポートと透視投影行列を設定します。
- `init()`
  背景色、深度テスト、カリング、ライティングを初期化します。
- `keyboard()`
  `q`, `Q`, `Esc` で終了します。

#### 2.5.1 マウス回転の仕組み

マウスドラッグによる回転には、クォータニオンが使われています。

1. ドラッグ開始位置を `mouse()` で記録する。
2. `motion()` でマウスの移動量から回転角を求める。
3. その回転をクォータニオン `dq` として表す。
4. `qmul()` で現在の回転 `cq` と合成し、新しい回転 `tq` を得る。
5. `qrot()` でクォータニオンを 4x4 回転行列 `rt` に変換する。
6. `display()` で `glMultMatrixd(rt)` を呼び、形状全体に回転を適用する。

クォータニオンを使う利点は、3 次元回転を安定して扱いやすく、回転の合成も簡潔に書ける点です。

## 3. ビルド方法と実行方法

このリポジトリには [CMakeLists.txt](CMakeLists.txt) が含まれており、Windows では Visual Studio 2022、macOS では Xcode、Lubuntu Linux では Unix Makefiles を生成できます。

### 3.1 Windows

#### 前提

- Visual Studio 2022
- CMake
- Git
- インターネット接続

Windows では CMake が `FetchContent` を用いて freeglut のソースコードを取得し、ビルドしてリンクします。

#### ソリューション生成

```powershell
cmake -S . -B build -G "Visual Studio 17 2022"
```

これにより、`build` 以下に Visual Studio 2022 用のソリューションが生成されます。スタートアッププロジェクトは `extrusion` に設定されます。

#### Visual Studio でビルドする場合

1. `build/extrusion.sln` を Visual Studio 2022 で開きます。
2. 構成を `Debug` または `Release` に設定します。
3. 実行する場合は、そのまま `F5` または `Ctrl+F5` を押します。

#### コマンドラインでビルドする場合

```powershell
cmake --build build --config Release
```

#### 実行ファイル

Release ビルド時の実行ファイルは通常、次に生成されます。

- `build/Release/extrusion.exe`

### 3.2 macOS

#### 前提

- Xcode
- CMake

macOS では GLUT.framework と OpenGL.framework をリンクし、Xcode 用のアプリケーションバンドル `extrusion.app` を生成します。

#### Xcode プロジェクト生成

```bash
cmake -S . -B build -G Xcode
```

#### Xcode でビルド・実行する場合

1. `build/extrusion.xcodeproj` を Xcode で開きます。
2. スキーム `extrusion` を選択します。
3. `Run` を実行すると `extrusion.app` が起動します。

#### コマンドラインでビルドする場合

```bash
cmake --build build --config Release
```

#### アプリケーションバンドル

Release ビルド時のアプリケーションは通常、次に生成されます。

- `build/Release/extrusion.app`

### 3.3 Lubuntu Linux

#### 前提

Lubuntu Linux では、システムにインストールされた freeglut の開発パッケージと `pkg-config` を使ってコンパイル時・リンク時のフラグを決定します。

Ubuntu 系では通常、次のパッケージを入れておけばビルドできます。

```bash
sudo apt update
sudo apt install build-essential cmake pkg-config freeglut3-dev
```

環境によってはパッケージ名が `freeglut-dev` 系で提供される場合があります。その場合は、`glut.pc` を提供する開発パッケージを導入してください。

#### Makefile 生成

```bash
cmake -S . -B build -G "Unix Makefiles"
```

#### ビルド

```bash
cmake --build build
```

#### 実行

```bash
./build/extrusion
```

X サーバ上で実行し、OpenGL/GLUT のウィンドウが表示されることを確認してください。

## 4. 実行時の操作

- マウス左ボタンを押したままドラッグすると形状を回転できます。
- `q`, `Q`, `Esc` を押すと終了します。

## 5. 学習のポイント

このプログラムからは、次の点を学べます。

1. 2 次元断面を 3 次元経路に沿って押し出して立体を作る方法
2. 折れ線経路の節点で断面の向きを調整する方法
3. 法線ベクトルを用いたライティング対応の基本
4. GLU テセレータを使った端面多角形の描画方法
5. クォータニオンを用いた 3 次元回転の扱い方

押し出し処理、座標変換、OpenGL 描画、対話的な回転操作が一通り含まれているため、コンピュータグラフィックスの教材として扱いやすい構成になっています。
